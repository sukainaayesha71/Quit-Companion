# Documentation guide

- [Android and backend completion](ANDROID_COMPLETION.md): current implementation
  record, runtime instructions, ML limitations and external release criteria.
- [Feature audit](FEATURE_AUDIT.md): original feature inventory; the completion
  record supersedes its older missing-code and setup findings.
- [ML candidate evaluation](ML_CANDIDATE_EVALUATION.json): reproducible research
  evaluation results.
- `superpowers/`: historical implementation plans and decisions; these are
  retained for context and are not the current completion checklist.

Firebase Console changes and device test results should be verified separately
from historical implementation records.
