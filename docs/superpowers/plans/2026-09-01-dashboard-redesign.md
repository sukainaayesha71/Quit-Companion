# Dashboard Redesign Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Redesign `mobile/lib/screens/dashboard/` to visually match `docs/UI_Design/dashboard 5.png` (illustrated background, restyled/reordered cards, a real "This Week" chart, entrance animations), rolled out in two stages: layout-with-placeholders first, then real-data wiring.

**Architecture:** A `Stack` in `DashboardScreen` layers a cropped-from-reference sky image at the top and a synthetic hill-green gradient at the bottom (static, non-interactive) behind the existing scrollable cream card. The bottom couldn't be a crop too — the reference's own cards/chart/milestone-card/FAB fill every horizontal band all the way to its baked-in nav bar, so there's no UI-free strip to extract; a gradient sampled from the same hill color is the honest fallback (decided with the user during Task 1). Inside the card, `NicotineFreeStateView` shrinks to just the hero+stats (its milestone/health-recovery cards move into `DashboardScreen` so they can be reordered after the new chart, per the reference). The "This Week" chart and the "logged today" badge get their data from two new controller-level fields (`weeklyTrend`, `pctBetterThanLastWeek`, `todaysCravingLogged`) computed from `CravingLogRepository.getRecentLogs`/`countLoggedSince` — deliberately placed on `DashboardController` rather than on `NicotineFreeState`, since both the chart and the Quick Access grid already render in the Countdown phase too, and craving-log activity isn't specific to the Nicotine-Free state.

**Tech Stack:** Flutter/Dart (existing `quit_companion` app), `flutter_test` widget/unit tests, no new pub packages (chart is a hand-rolled `CustomPainter`), Python 3 + Pillow for the one-time asset-extraction script.

## Global Constraints

- No new pub dependencies (project convention: hand-roll simple things like `formatMoney` rather than pull in a package) — the chart is a `CustomPainter`, not a chart library.
- Never fabricate data: every displayed number must trace to a real repository call. Stage 1 uses explicit, clearly-scoped placeholder constants inside `DashboardScreen` (removed in Stage 2), never inside the calculator/controller.
- Don't change existing method signatures on `DashboardStateCalculator.calculate` or `CravingLogRepository` — only add new, independent computations alongside them, so all currently-passing tests keep passing untouched.
- Follow existing key-naming convention for widget test hooks: `dashboard_<thing>` (e.g. `dashboard_quick_access_log_craving`).
- Colors: use existing `AppColors` constants only (`background`, `surface`, `sage`/`sageDark`/`sageLight`, `terracotta`/`terracottaDark`/`terracottaLight`, `textPrimary`, `textSecondary`, `border`) — don't invent new hex values.

```python
# mobile/tool/extract_dashboard_background.py
"""One-time tool: crops the sky band (top) out of docs/UI_Design/dashboard
5.png for use as the Dashboard screen's background.

Only the top band is extracted this way — the reference's bottom half has
cards/chart/milestone-card/FAB stacked edge-to-edge all the way to its own
baked-in nav bar, so there's no horizontal band anywhere that's pure
hills/path with zero UI content to crop cleanly. The bottom illustration is
instead a plain Flutter gradient (see Task 2), sampled from the same hill
green this image contains (~RGB 140,164,136, already close to
AppColors.heroHill).

Re-run and adjust TOP_FRACTION if the reference art changes.
"""
from pathlib import Path
from PIL import Image

SOURCE = Path(__file__).resolve().parents[2] / "docs" / "UI_Design" / "dashboard 5.png"
OUT_DIR = Path(__file__).resolve().parents[1] / "assets" / "images"

# Fraction of total image height, tuned by visual inspection of the cropped
# output (Step 2) — the reference's card starts almost immediately, so this
# is a thin sliver of pure sky/sun/clouds/birds.
TOP_FRACTION = 0.045


def main():
    img = Image.open(SOURCE).convert("RGB")
    w, h = img.size
    top_crop = img.crop((0, 0, w, int(h * TOP_FRACTION)))
    OUT_DIR.mkdir(parents=True, exist_ok=True)
    top_crop.save(OUT_DIR / "dashboard_bg_top.png")
    print(f"Wrote {OUT_DIR / 'dashboard_bg_top.png'} {top_crop.size}")


if __name__ == "__main__":
    main()
```

```dart
// mobile/lib/screens/dashboard/widgets/weekly_trend_chart_painter.dart
import 'package:flutter/material.dart';
import '../../../theme/app_theme.dart';

/// Smooth area/line chart for the "This Week" card (docs/UI_Design/
/// dashboard 5.png) — 7 daily values, oldest first. Pure presentation: takes
/// whatever counts the caller passes, invents nothing.
class WeeklyTrendChartPainter extends CustomPainter {
  final List<int> values;

  WeeklyTrendChartPainter(this.values) : assert(values.length == 7);

  @override
  void paint(Canvas canvas, Size size) {
    final maxValue = values.reduce((a, b) => a > b ? a : b).clamp(1, 1 << 30);
    final stepX = size.width / (values.length - 1);
    final points = <Offset>[
      for (var i = 0; i < values.length; i++)
        Offset(i * stepX, size.height - (values[i] / maxValue) * size.height * 0.85),
    ];

    final linePath = Path()..moveTo(points.first.dx, points.first.dy);
    for (var i = 0; i < points.length - 1; i++) {
      final mid = Offset((points[i].dx + points[i + 1].dx) / 2, (points[i].dy + points[i + 1].dy) / 2);
      linePath.quadraticBezierTo(points[i].dx, points[i].dy, mid.dx, mid.dy);
    }
    linePath.lineTo(points.last.dx, points.last.dy);

    final fillPath = Path.from(linePath)
      ..lineTo(points.last.dx, size.height)
      ..lineTo(points.first.dx, size.height)
      ..close();

    final fillPaint = Paint()
      ..shader = LinearGradient(
        begin: Alignment.topCenter,
        end: Alignment.bottomCenter,
        colors: [AppColors.sage.withValues(alpha: 0.35), AppColors.sage.withValues(alpha: 0.0)],
      ).createShader(Rect.fromLTWH(0, 0, size.width, size.height));
    canvas.drawPath(fillPath, fillPaint);

    final linePaint = Paint()
      ..color = AppColors.terracotta
      ..style = PaintingStyle.stroke
      ..strokeWidth = 2.5
      ..strokeCap = StrokeCap.round;
    canvas.drawPath(linePath, linePaint);

    final dotPaint = Paint()..color = AppColors.terracotta;
    final dotHaloPaint = Paint()..color = AppColors.surface;
    for (final point in points) {
      canvas.drawCircle(point, 5, dotHaloPaint);
      canvas.drawCircle(point, 3.5, dotPaint);
    }
  }

  @override
  bool shouldRepaint(covariant WeeklyTrendChartPainter oldDelegate) => oldDelegate.values != values;
}
```

```dart
/// "This Week" card (docs/UI_Design/dashboard 5.png): a 7-day trend chart

class WeeklyProgressCard extends StatelessWidget {
  final List<int> trend;
  final double? pctBetterThanLastWeek;

  const WeeklyProgressCard({super.key, required this.trend, required this.pctBetterThanLastWeek})
      : assert(trend.length == 7);

  @override
  Widget build(BuildContext context) {
    final pct = pctBetterThanLastWeek;
    return Container(
      key: const Key('dashboard_weekly_progress_card'),
      padding: const EdgeInsets.all(20),
      decoration: BoxDecoration(
        color: AppColors.surface,
        borderRadius: BorderRadius.circular(20),
        boxShadow: [
          BoxShadow(color: Colors.black.withValues(alpha: 0.04), blurRadius: 12, offset: const Offset(0, 4)),
        ],
      ),
      child: Column(
        crossAxisAlignment: CrossAxisAlignment.start,
        children: [
          Row(
            mainAxisAlignment: MainAxisAlignment.spaceBetween,

              if (pct != null)
                Container(

                    borderRadius: BorderRadius.circular(12),
```

```dart
// mobile/lib/domain/weekly_trend_calculator.dart
import '../models/craving_log.dart';

/// Buckets craving logs into a 7-day trend for the Dashboard's "This Week"
/// chart, plus a week-over-week comparison. Pure — no I/O; DashboardController
/// fetches the logs and passes them in, mirroring DashboardStateCalculator's
/// style. Not tied to NicotineFreeState: craving-log activity (and therefore
/// the chart) is meaningful in the Countdown phase too.
class WeeklyTrendCalculator {
  final DateTime Function() now;

  WeeklyTrendCalculator({DateTime Function()? now}) : now = now ?? DateTime.now;

  /// [recentLogs] should cover at least the last 14 days; anything older is
  /// ignored. Returns 7 daily counts (oldest first, ending today) for
  /// [weeklyTrend], and the percentage change in total craving-log count vs.
  /// the prior 7 days for [pctBetterThanLastWeek] — positive means fewer
  /// logs this week (improvement), negative means more. Null when the prior
  /// week has zero logs, since there's nothing honest to compare against.
  ({List<int> weeklyTrend, double? pctBetterThanLastWeek}) calculate(List<CravingLog> recentLogs) {
    final today = _dateOnly(now());
    final counts = <DateTime, int>{};
    for (final log in recentLogs) {
      final day = _dateOnly(log.timestamp);
      counts[day] = (counts[day] ?? 0) + 1;
    }

    final weeklyTrend = <int>[
      for (var i = 6; i >= 0; i--) counts[today.subtract(Duration(days: i))] ?? 0,
    ];
    final thisWeekTotal = weeklyTrend.fold<int>(0, (sum, v) => sum + v);

    var lastWeekTotal = 0;
    for (var i = 7; i <= 13; i++) {
      lastWeekTotal += counts[today.subtract(Duration(days: i))] ?? 0;
    }

    final pctBetterThanLastWeek =
        lastWeekTotal == 0 ? null : ((lastWeekTotal - thisWeekTotal) / lastWeekTotal) * 100;

    return (weeklyTrend: weeklyTrend, pctBetterThanLastWeek: pctBetterThanLastWeek);
  }

  DateTime _dateOnly(DateTime dt) => DateTime(dt.year, dt.month, dt.day);
}
```
